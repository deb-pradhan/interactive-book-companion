# Examples

## design-preview.html

A live, self-contained preview of the **updated design system** applied to *Atomic Habits*.
Open it in a browser (or view the hosted version linked from the main README).

It exists to show the target look the skill should produce:

- A graphical dashboard: colored stat-card grid, a striped bar chart with a black value pill,
  a donut with a legend, a multi-arc progress ring, a black feature card, category chips, and
  icon-led principle cards.
- The **animated, four-level mind map**: a thesis at the center, color-coded major-idea branches,
  and subtopics and details that expand on click, with idle drift, flowing edges, pan/zoom, and
  a detail drawer for every node.
- Light (periwinkle brand) and dark themes.

This file is a hand-built design reference, not the literal output of the skill. The skill
generates a companion tailored to whatever book it is given, following this same design system.
